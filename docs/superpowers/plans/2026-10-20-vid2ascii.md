# vid2ascii Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A CLI (`python -m vid2ascii in.mp4 -o out.mp4`) that converts any local video into an ASCII-character video with the original audio.

**Architecture:** ffmpeg crops and downsamples each frame straight to the character grid and pipes rgb24 into numpy. numpy maps brightness to ramp indices and builds full-size frames by indexing a pre-rendered glyph atlas. Raw frames are piped into a second ffmpeg, which muxes in the original audio cut to the same range.

**Tech Stack:** Python 3.13, numpy, Pillow, tqdm, librosa (beat only), pytest, ffmpeg/ffprobe on PATH.

**Spec:** `docs/superpowers/specs/2026-10-20-vid2ascii-design.md`

## Global Constraints

- Decode and encode only via ffmpeg pipes. No temp frame folders and no per-frame image files (preview PNGs are the only exception).
- Never draw text per cell. Glyphs are rendered once into the atlas, and frames are built by numpy indexing.
- Duration max 60s. Defaults: `--fps 24`, `--cols 120`, `--color original`, `--charset standard`, `--contrast auto`.
- `standard` ramp is exactly `" .:-=+*#%@"`.
- Output long side 1920px. Aspect matches the input unless `--aspect` is given. A different aspect is center-cropped to fill.
- Cell width `cw` and height `ch` are both even, so output dims are even.
- Errors: subclasses of `Vid2AsciiError`. The CLI prints `error: <msg>` to stderr and exits with code 2.
- Never download from the network. Local files only.
- Run tests with `python -m pytest` from the repo root.
- Windows paths with spaces must work: always pass subprocess args as lists, never `shell=True`.

## Review Focus

1. **Paths with spaces/unicode** (e.g. `my clip ü.mp4`) should convert normally. Pinned in Task 6 (`test_path_with_spaces`).
2. **`--start` at or past the end of the video** should give a clear `InputError`, not an empty mp4. Pinned in Task 6 (`test_start_past_end`).
3. **NTSC/odd source fps (29.97) and odd source dims (e.g. 641x359)** should still give exact `--fps` output and even dims. Pinned in Task 5 (`test_iter_frames_odd_source`).
4. **Tiny sources smaller than the grid** (e.g. 64x36 at 120 cols) should upscale to the grid without crashing. Pinned in Task 5 (same test).
5. **Black frames** (all zero) in `original` color mode should not cause divide-by-zero NaNs and should give a valid uint8 frame. Pinned in Task 3 (`test_tint_black_frame_no_nan`).

### Task 1: Glyph atlas (`atlas.py`)

**Interfaces – Produces:**
- `CHARSETS: dict[str, str]` with `standard=" .:-=+*#%@"`, `detailed` (70 chars, `" .'`^\",:;Il!i><~+_-?][}{1)(|\\/tfjrxnuvczXYUJCLQ0OZmwqpdbkhao*#MW&8%B@$"`), `blocks=" ░▒▓█"`, `binary=" 01"`.
- `resolve_charset(name_or_chars: str) -> str`: returns the preset for a known name, otherwise the string itself. Raises `ValueError` when the result has fewer than 2 chars.
- `find_font(path: str | None = None) -> str`: an explicit path must exist, otherwise `FontError`. The candidate list covers `consola.ttf`, `CascadiaMono.ttf`, `cour.ttf` (Windows `%WINDIR%\Fonts`), `Menlo.ttc`/`Courier New.ttf` (macOS), and `DejaVuSansMono.ttf` (Linux `/usr/share/fonts/**`). None found raises `FontError` with a "use --font PATH" hint.
- `font_cell_ratio(font_path: str) -> tuple[float, float]`: `(advance_width, line_height)` of the font at size 100.
- `build_atlas(chars: str, font_path: str, cw: int, ch: int) -> np.ndarray`: float32 `(len(chars), ch, cw)` in [0,1]. Pick the largest font size whose `"@"` and `"█"` bbox fits the cell, then center each glyph.

### Task 2: Aspect and layout math (`frames.py`, pure part)

**Interfaces – Produces:**
- `@dataclass(frozen=True) Layout(cols:int, rows:int, cw:int, ch:int, out_w:int, out_h:int)`.
- `ASPECTS = {"reel": 9/16, "square": 1.0, "wide": 16/9, "cinematic": 2.39}`.
- `parse_aspect(spec: str | None, src_w: int, src_h: int) -> float`: `None` or `"source"` gives `src_w/src_h`; a preset name gives its value; `"WxH"` gives `W/H`. Anything else raises `ValueError`.
- `compute_layout(aspect: float, cols: int, font_w: float, font_h: float, long_side: int = 1920) -> Layout`. The algorithm:
  ```
  W,H = (long_side, long_side/aspect) if aspect>=1 else (long_side*aspect, long_side)
  cw = even(max(4, round(W/cols)));  ch = even(max(4, round(cw*font_h/font_w)))
  rows = max(1, round(H/ch));  out = (cols*cw, rows*ch)
  even(x) = x + (x % 2)
  ```
- `crop_filter(src_w: int, src_h: int, aspect: float) -> str`: `""` if `|src_w/src_h - aspect|/aspect < 0.01`. Otherwise a wider source gives `crop=<even w>:<src_h>`, and a taller one gives `crop=<src_w>:<even h>`. Both are centered (ffmpeg's crop default).

### Task 3: Renderer (`render.py`)

**Interfaces – Produces:**
- `luminance(rgb: np.ndarray) -> np.ndarray`: uint8 `(r,c,3)` to float32 `(r,c)` in [0,1], with weights 0.2126/0.7152/0.0722.
- `class AutoContrast(mode: str | float = "auto")`, with `__call__(lum) -> lum`:
  - `"auto"`: 2nd and 98th percentiles, EMA α=0.2 (the first frame initializes it), stretch, clip, then gamma 0.7 when the stretched mean < 0.35.
  - `"none"`: identity.
  - A float `g`: `clip((lum-0.5)*g+0.5)`.
  - Parse `"1.5"` strings as floats. Anything else raises ValueError.
- `map_to_indices(lum, n_chars) -> np.ndarray[int64]`: `clip(floor(lum*n), 0, n-1)`.
- `compose(indices, atlas) -> np.ndarray`: float32 `(rows*ch, cols*cw)` via `atlas[indices].transpose(0,2,1,3).reshape(...)`.
- `COLORS = {"green": (0x33,0xff,0x66), "amber": (0xff,0xb0,0x00), "mono": (255,255,255)}`.
- `tint(mask, rgb_cells, mode, cw, ch) -> np.ndarray`: uint8 `(H,W,3)`.
  - `original`: cell color c/255 scaled by `max(m,0.35)/max(m,1e-6)` where m is the per-cell max channel. A pure-black cell becomes gray 0.35. Upscale via `np.repeat` on both axes, multiply by mask.
- `beat_indices(indices, strength, n_chars, rng) -> np.ndarray`: shift by `round(strength*n*0.3)` (clipped), then set a `0.15*strength` fraction of the cells to `rng.integers(1, n)`. Identity when strength <= 0.
- `class Renderer(atlas: np.ndarray, color: str = "original", contrast="auto", seed: int = 0)`, with `render(rgb_cells, beat_strength: float = 0.0) -> uint8 (rows*ch, cols*cw, 3)`. Pipeline: luminance, then contrast, then `+0.35*s` boost and clip, then indices, then beat_indices, then compose, then tint.

  - `test_map_monotonic`: `np.diff(map_to_indices(np.linspace(0,1,100),10)) >= 0`.
  - `test_compose_shape_and_values`: a 2x3 indices grid gives shape `(8,6)`, and cell (1,2) equals `atlas[idx[1,2]]`.
  - `test_tint_green`: all-bright gives `[0x33,0xff,0x66]` everywhere.
  - `test_tint_black_frame_no_nan`: zeros rgb in original mode gives no NaN, dtype uint8.
  - `test_autocontrast_lifts_dark`: lum uniform in [0.05,0.15] gives an output mean > 0.35 and a max ≥ 0.9.
  - `test_autocontrast_none_identity`.
  - `test_beat_indices_changes_and_identity`: strength 0 gives an equal array, strength 1 gives a mean index higher.
  - `test_renderer_output`: a 3x4 grid gives uint8 `(12,8,3)`.

### Task 5: Probe and frame decode (`frames.py`, ffmpeg part)

**Interfaces – Consumes:** Task 2 `Layout`, `crop_filter`.

**Interfaces – Produces:**
- `require_ffmpeg() -> None`: raises `FFmpegNotFound` with install hints if `shutil.which` can't find ffmpeg or ffprobe.
- `@dataclass(frozen=True) VideoInfo(width:int, height:int, fps:float, duration:float, has_audio:bool)`.
- `probe(path) -> VideoInfo`: ffprobe `-show_streams -show_format -of json`. A missing file, a non-zero exit, or no video stream raises `InputError(f"cannot read video: {path}")`. fps comes from `avg_frame_rate` (fall back to `r_frame_rate`). duration comes from format, then stream.
- `iter_frames(path, info: VideoInfo, start: float, duration: float, fps: float, layout: Layout, aspect: float) -> Iterator[np.ndarray]`: yields uint8 `(rows, cols, 3)`. The filter chain is `fps=F,[crop,]scale=cols:rows:flags=area,format=rgb24`, and the output is `-f rawvideo`. Read exactly `rows*cols*3` bytes per frame and stop on a short read. Use `-ss` before `-i`. Kill the process in `finally`.

### Task 6: CLI, encoder, preview, folder mode (`cli.py`)

**Interfaces – Consumes:** everything above.

**Interfaces – Produces:**
- `build_parser() -> argparse.ArgumentParser` with: `input`, `-o/--output`, `--start` (float, 0), `--duration` (float, None), `--fps` (float, 24), `--cols` (int, 120), `--color` (choices original|green|amber|mono), `--charset` ("standard"), `--contrast` ("auto"), `--beat` (flag), `--preview` (int, 0), `--aspect` (None), `--font` (None), `--overwrite` (flag).
- `convert(input_path: Path, output_path: Path, args: argparse.Namespace) -> Path`. Steps:
  1. `probe`, then clamp the duration to `min(60, args.duration or inf, info.duration - start)`. If that's ≤ 0, raise `InputError("--start is past the end of the video")`.
  2. aspect and layout (font ratio from `find_font`), atlas, `Renderer`.
  3. Beat envelope if `--beat` (when the clip has no audio, warn and skip).
  4. `n_frames = max(1, round(dur*fps))`.
  5. If preview: indices `linspace(0, n_frames-1, N)` rounded. Render those frames and save `<out_stem>_preview_01.png` and so on next to the output. Return the output dir.
  6. Otherwise, the encoder: `ffmpeg -y -f rawvideo -pix_fmt rgb24 -s WxH -r fps -i - [-ss start -t dur -i input -map 0:v -map 1:a -c:a aac -b:a 192k] -c:v libx264 -preset veryfast -crf 20 -pix_fmt yuv420p -shortest -movflags +faststart out`. Write each frame's bytes to stdin, with tqdm over n_frames. Collect stderr in a background thread. A non-zero exit raises `Vid2AsciiError` with the last 15 stderr lines.
- `main(argv: list[str] | None = None) -> int`:
  - Call `require_ffmpeg()`.
  - A directory input means folder mode: default out `<dir>/ascii_out/`, convert each video extension, catch `Vid2AsciiError` per file, print a summary, and return 0 if all succeeded, otherwise 1.
  - A file input: the default output is `<stem>_ascii.mp4`. An existing output without `--overwrite` raises an error.
  - Catch `Vid2AsciiError` and `ValueError`, print `error: ...`, and return 2.
